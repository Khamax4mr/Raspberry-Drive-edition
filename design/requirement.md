## 기능 요구사항

### 저장소 생성
- [ ] 사용자의 USB 장치 연결을 인식하면 본 기능을 수행한다.
- [ ] USB 장치가 디스크이고 마운트 상태가 아니라면 드라이브 폴더에 새 USB 장치의 저장소를 만든다.
- [ ] 새 USB 장치의 저장소 폴더 이름은 장치의 고유 번호로 정한다.
- [ ] 새 USB 장치를 저장소 폴더에 마운트한다.
- [ ] 드라이브 폴더에 저장소 폴더에 대응하는 [언마운트 파일](#저장소-삭제)을 만든다.

### 저장소 삭제
- [ ] 언마운트 파일을 실행하면 본 기능을 수행한다.
- [ ] 저장소 폴더가 마운트 상태라면 USB 장치의 마운트를 해제한다.
- [ ] 저장소 폴더가 마운트 상태가 아니면 저장소 폴더, 대응하는 언마운트 파일을 삭제한다.

# 비기능 요구사항

## 시스템

### 장비
|유형|사양|
|---|---|
|모델|Raspberry Pi 3B rev 1.2|
|운영체제|Raspberry Pi OS 13|
|아키텍처|aarch64|
|USB Port|4|


### 기술
|기능|사용 기술|
|---|---|
|네트워크 드라이브|Samba|


## 사용성

### 설치
- [ ] 설치 스크립트 실행에는 `sudo` 권한이 필요하다.
- [ ] 드라이브 시스템 동작에 필요한 패키지를 자동으로 설치한다.
- [ ] 지정한 경로에 드라이브 폴더를 만든다.

### 연결
- [ ] 드라이브 시스템은 SMB 프로토콜 연결을 지원한다.

### 운영
- [ ] 모든 드라이브 시스템 동작은 드라이브 폴더 안에서만 일어난다.
